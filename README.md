# Travel Planner

A modern, responsive single-page Travel Planner web application built using HTML, CSS, and JavaScript. This project was developed as part of an AI course assignment with a focus on creating a professional user interface and integrating real-time country data using the REST Countries API.

## Features

- Modern and responsive single-page interface
- Clean and user-friendly UI/UX
- Country search using the REST Countries API
- Display of country information including:
  - Flag
  - Capital
  - Region
  - Population
  - Currency
  - Languages
- Interactive destination cards
- Travel guide modal for featured destinations
- Smooth animations and hover effects
- Loading indicator during API requests
- User-friendly error handling
- Mobile-friendly responsive design
- Clean and modular code structure

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- REST Countries API
